Aim

To create an Android application that demonstrates navigation between multiple activities using Explicit Intents.

Concept

An Intent is used to communicate between Android components.

This experiment uses Explicit Intent to navigate from one activity to another activity within the same application.

Application Description

The application contains multiple screens:

- Main Activity: Student login page
- Second Activity: Displays the next screen after login
- Third Activity: Displays the student's details/result

The application demonstrates how data can be passed between activities using intents.

Technologies Used

- Android Studio
- Kotlin
- XML
- Explicit Intent

Test Cases

Test Case 1

Input: Enter valid student details.
Expected Result: The application navigates to the next activity successfully.

Test Case 2

Input: Navigate through the application using the provided buttons.
Expected Result: The corresponding activities open successfully.

Test Case 3

Input: Enter/display student name and USN.
